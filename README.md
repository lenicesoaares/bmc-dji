# Business Model Canvas – DJI

Interactive presentation of the Business Model Canvas of **DJI**, made for the Canva business plan task (English class).

🔗 **Website:** https://lenicesoaares.github.io/bmc-dji/

## How to use
- Click on a block to reveal the information
- **Reveal next** (or the space bar) opens the blocks one by one, in presentation order
- **Reveal all** opens all the blocks
- **Reset** closes them again

## The 9 blocks
Customer Segments · Value Propositions · Channels · Customer Relationship · Revenue Stream · Key Resources · Key Activities · Key Partners · Cost Structure
